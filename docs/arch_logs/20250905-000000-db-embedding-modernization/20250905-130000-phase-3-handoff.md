### 1. Job Queue Schema & Operations
**Location**: `packages/db/src/migrations/007-job-queue.ts`

```sql
-- Complete job queue table with all operational columns
CREATE TABLE job_queue (
  id UUID PRIMARY KEY,
  queue TEXT NOT NULL,
  job_type TEXT NOT NULL,
  payload JSONB NOT NULL,
  state TEXT NOT NULL DEFAULT 'queued',
  run_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  attempts INTEGER NOT NULL DEFAULT 0,
  max_attempts INTEGER NOT NULL DEFAULT 3,
  backoff_ms INTEGER NOT NULL DEFAULT 1000,
  lease_token UUID,
  leased_until TIMESTAMPTZ,
  worker_id TEXT,
  dedupe_key TEXT,
  error TEXT,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- Critical indexes for performance
CREATE INDEX idx_job_queue_claim ON job_queue(queue, state, run_at);
CREATE INDEX idx_job_queue_lease ON job_queue(state, leased_until);
CREATE UNIQUE INDEX idx_job_queue_dedupe ON job_queue(dedupe_key) WHERE dedupe_key IS NOT NULL;
```

### 2. Queue API Implementation
**Location**: `packages/db/src/queue/job-queue.ts`

```typescript
export class JobQueue {
  // Atomic job claiming with lease management
  async claim({ queue, leaseMs }: ClaimOptions): Promise<Job | null>
  
  // Enqueue with deduplication support
  async enqueue(job: EnqueueJobRequest): Promise<Job>
  
  // Lease management and heartbeats
  async heartbeat(id: string, leaseToken: string, extendMs: number): Promise<void>
  
  // Job completion with automatic cleanup
  async complete(id: string, leaseToken: string): Promise<void>
  async fail(id: string, leaseToken: string, error: string): Promise<void>
  
  // Administrative operations
  async getCountsByState(): Promise<{ [state: string]: number }>
  async clear(queue?: string, states?: JobState[]): Promise<number>
  async requeueFailed(queue?: string, limit?: number): Promise<number>
}
```

**Key features:**
- **Atomic claiming**: `UPDATE ... RETURNING` prevents race conditions
- **Exponential backoff**: `Math.min(1000 * Math.pow(2, attempts), 300000)` with jitter
- **Lease management**: Prevents worker stalls with heartbeat system
- **Deduplication**: `chunk_id + ':' + embedding_set_id + ':' + content_hash`

### 3. Producer Integration
**Location**: `packages/file-import/src/chunking.ts`

```typescript
// Automatic job enqueuing after successful chunk insertion
export class ChunkingProducer {
  async enqueueEmbeddingJobs(chunks: FileChunk[], embeddingSetId: string): Promise<void> {
    if (process.env.EMBED_QUEUE_ENABLED !== 'true') return;
    
    for (const chunk of chunks) {
      await this.jobQueue.enqueue({
        queue: 'embeddings',
        jobType: 'embed_chunk',
        payload: { chunkId: chunk.id, embeddingSetId },
        dedupeKey: `${chunk.id}:${embeddingSetId}:${chunk.contentHash}`,
      });
    }
  }
}
```

### 2. Job Deduplication  
Jobs are deduplicated using: `${chunkId}:${embeddingSetId}:${contentHash}`
- This prevents duplicate work when re-importing same content
- Workers should check `embedding_hash` before processing
- Idempotent operations ensure safe retries

## Post-Review Deltas (Applied before Phase 4)

Based on review feedback, we tightened the queue semantics and added small infra improvements to ensure Phase 4 workers behave correctly under crashes/restarts:

- Claiming: `claim()` now also picks up expired `running` jobs and increments `attempts` atomically on claim. It excludes jobs where `attempts >= max_attempts`.
- Dedup upsert: `enqueue()` uses `INSERT ... ON CONFLICT (dedupe_key) DO UPDATE` keeping the earliest `run_at` and refreshing `updated_at` (idempotent enqueue).
- Backoff discipline: Attempts are incremented on claim only; `fail()` computes backoff from current attempts and requeues or marks failed accordingly.
- Transactional producer: `processChunking()` supports an injected transaction runner; when queueing is enabled, chunk inserts and job enqueues are executed in a single DB transaction. Repositories gained `insertManyWithTx()` to avoid nested transactions.
- Admin utilities: Added `expireLeases()` and `prune(states, olderThan)` to keep tables healthy. CLI gained `prune`.
- Indexing: Added `idx_job_queue_claim(queue, state, run_at, id)` for deterministic ordering.

# Archived docs

Dated, one-shot documents that have served their purpose: handoffs, root-cause
write-ups, migration/PR plans, and point-in-time research or benchmark reports.
They are kept for the historical record — **frozen as written, not maintained.**

Treat anything here as a snapshot of what was true on its date. It may describe
code, file paths, or decisions that have since changed. For current behavior,
start from `AGENTS.md` and the live subsystem contracts in
[`docs/agents/`](../agents/), which are living documents.

Files live at the repo's `docs/` root — not here — when they are still
referenced by code, tests, CI workflows, or tool config (moving those would mean
churning source in a docs change), or when they describe an ongoing effort.
That rule, not age alone, is what decides whether a doc gets archived.

# Explicit canonical VECTOR pipeline

Explicit VECTOR consumes the saved current full profile, native scoped prepare/commit and real missing chunk IDs, and joins inference before publication. TEXT keeps its existing default, receipts and zero profile/inference calls.

On 2026-10-03 the accepted host used only `commitTextFile`; its exported inference port and catalog resolver were unused. `CanonicalIngestionDependencies` now distinguishes TEXT/VECTOR, and `CanonicalVectorPublicationPort` maps directly to the existing `ScopedIndexerPort` prepare, commit, complete scoped manifest and selected-profile coverage operations. No source scanner/parser/coordinator, PG adapter, inference host or native engine is duplicated.

The host preserves original source, canonical provided metadata and nullable collection identity. It validates plans and inference responses against source/store/scope/full-profile identity, chunks/order/dimensions/finite vectors, rechecks saved profile around awaited work, and uses only the native plan's missing vectors. Unique inference operation IDs preserve transport ownership. Errors stop admission; cancellation, join failures and abort-notice failures remain visible. Failed joins/notices block reuse and explicit close retries their owners.

The public native interface supplies coverage counts and accepts complete scoped manifests but exposes no complete canonical chunk-inventory reader. A file/hash or receipt cannot supply the skipped file's canonical chunk metadata. Consequently VECTOR rereads/reparses sources to construct its full manifest, including stat-cache hits; no new cache/store or weaker completeness predicate conceals that cost. Already covered chunks produce no inference calls. Repeated VECTOR scan performance is unqualified. TEXT skipping is unchanged.

Focused RED/GREEN tests exercise TEXT isolation, workspace/rootless original-source backfill, malformed plans/responses, profile changes, exact full-scope proof, held physical inference/publication joins, late cancellation during join, independent AbortError and failed notice preservation, and retry after join failure. Public built Node host plus actual native writer integration uses controlled inference, exercises multiple bounded ordered batches, TEXT backfill, vector reuse and reopen, and refuses incomplete trusted binding inventory. Controlled inference does not qualify hidden model/device/Electron/main/closed-window/performance behavior. Existing main/utility owners still must wire live saved-mode authority, PG callbacks, scoped writer admission/receipts and the physical hidden-renderer relay.

CI is disabled due to cost; validation must run locally. Actual commands/results and immutable delivery identities are recorded in the task handoff.

Cancellation uses the inference owner's joined disposition, never an AbortError-name test. The existing NativeCanonicalInference completion normalizes only its exact owned cancellation reason and rethrows independent errors through both cancel/join. The host maps a failed generate to its own caller reason only after both owned cancellation and physical join succeed; host validation faults and independently rejected joins stay visible. Main/utility transport implementations of CanonicalInferencePort must preserve this disposition contract.

# Collapsed activity body work

Supports `assistant-runtime.md` § "ACTIVITY GROUPS".

Keep the collapsed body shell, DOM and manual disclosure state, while React's public `Activity` boundary hides its children, cleans display Effects/subscriptions, and renders new props at lower priority. Runtime history, receiver ownership and approval cards remain outside the boundary. The first matching registered tool-result renderer may declare `preserveEffectsWhenHidden`; such a group remains mounted outside Activity because hidden Effect cleanup must not close a live host session. Delegation cards route before result renderers and cannot claim this exception. Reference: [React Activity](https://react.dev/reference/react/Activity).

## 2026-09-30 bounded measurement

The private natural scoped replay uses the actual decoder, receiver, child store, root panel and two child panels, with 907 envelopes and 1,151,855 bytes from captured native input/output. No payload multiplication, model requests, live database connections, feature disabling, or vendor patches. The production host envelope is vendor out-of-band `2` with an array payload; the root must not retain child envelope parts. An inherited earlier harness used indexed `aui-data`, which artificially retained them in the root. Its >30-second completion failures and excess root render counts are superseded for production attribution.

With corrected production framing and the same 5 ms feed, the existing collapsed body completed in 13.242 seconds; the Activity candidate completed in 10.814 seconds. Both passed the unchanged 30-second delivery deadline and 1-second heartbeat bound. Max heartbeat delay was 236.7 / 214.1 ms. Summed child React render duration was 4.914 / 3.818 seconds. Both retained 46 hidden bodies and 5,066 descendant DOM nodes. These are one matched sample pair with recorder overhead, not a statistical benchmark or reproduction of the original 12.98-second single renderer freeze. The current native census independently found 16,636 descendants inside 173 collapsed bodies, but that larger live workload was not reproduced in this fixture.

The deterministic actual-ActivityTrace guard failed on the original code because its collapsed child kept one external-store display subscription. With Activity, it has zero while hidden, one when visible, no callbacks for 20 canonical updates while hidden, then restores the same detail DOM node, manual open state and latest value. The corrected full captured replay separately verifies exact child text/tool IDs/args/results, sibling ownership, no child envelope parts in root content, and nested captured detail state across collapse/reopen. The public decoded canvas approval test verifies the pending card remains visible outside collapsed activity bodies and actually resumes after Approve.

Conditional unmount was rejected because it destroys manual detail state. Wrapping external-store notifications in `startTransition` was rejected because React documents that external-store mutations cannot become nonblocking transitions. Store progressive notifications already coalesce on one 16 ms timer; terminal notifications remain immediate. No scroll-follow scheduling or context token counting contract changed.

Keep Activity mounted throughout and change only its mode to visible while expanded or while the registered renderer owns Effects; the body shell still hides collapsed markup. The guard preserves the identical sibling DOM node and manual disclosure through both ownership transitions, including hidden progressive output. The edit composer is extracted without changing its budget gate or public panel interface so the panel remains within its existing source-file line ceiling.

The ownership predicate for activity groups and hidden panes is shared, including delegation precedence.

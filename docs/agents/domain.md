# Project vocabulary

- Use the terms in current source, accepted ADRs and the relevant subsystem contract.
  - There is no glossary yet. If one is created from owner-approved decisions, it is the root `CONTEXT.md`.
  - Don't treat competing synonyms as settled; check current source, not dated plans.
- Use defined terms consistently in issue titles, proposals and code.
  - A missing concept is a vocabulary question, not permission to create another durable ID or owner.
  - When a proposal contradicts an accepted decision, name the conflict and get the owner's decision.
- Related: [issue tracker](issue-tracker.md), [triage vocabulary](triage-labels.md), `docs/adr/`.

# Foreground query lifecycle ownership

Supports `docs/agents/local-inference.md` § "Foreground query coordination".

Each DB/runtime generation owns one FIFO for cached service selection, initialization and query generation. Closing that generation fences preparation immediately; its public inference signal requests cancellation and the separate inference promise retains ownership until actual queue settlement. Non-inference preparation is never joined during physical teardown.

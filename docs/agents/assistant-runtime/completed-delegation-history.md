persona tool. This is a renderer projection; it does not admit a decision,
write a result, or infer effect completion from an approval receipt.

mount the follow-up executor. This is fixture coordination, not a production defect. It is not an
exact captured-wire replay. Before the correction, final results and successful
terminal events left the original group active with waiting glyphs. The corrected
projection leaves zero running infinite animations, retains pending siblings
until terminal evidence arrives, and rejects foreign generations, missing or
conflicting owners, foreign tools and failed terminal events. Existing canvas
and chained approval browser tests preserve active execution and separate host

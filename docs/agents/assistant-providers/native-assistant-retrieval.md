# Native desktop assistant retrieval

Desktop semantic and hybrid calls use the same main-owned scoped native capability as workspace search, with the exact saved query inference plan. The capability remains the sole authority and reader owner; PG remains the catalog and application-state owner.

On 2026-10-03 the production tools still searched PG vectors after generating queries without the native inference plan, although native ingestion replaces those vectors. A production-entry negative control failed nine native assertions while the no-native PG control passed. The cutover adds only an optional capability injection through the existing assistant options, dependencies and search executors.

The native capability represents collection or workspace scopes. Omitted tool collection inputs resolve from the actual main-owned saved authority; stale renderer workspace-index status cannot redirect or disable an otherwise ready native request. An exact root request uses the workspace scope and validates every returned chunk against both that root and the authorized selected collection. It cannot represent file/snapshot/chunk filters; those inputs explicitly refuse. Fixed equal RRF60 fusion reuses the workspace-search helper over BM25, killable grep and vector pools. Native limits above 10 refuse, and bounded-pool/output limitations reach model projections. Query thresholds retain the tools' declared cosine-similarity meaning.

Controlled unit tests hold real EmbeddingHostManager requests through caller cancellation and prove that tool promises and pending identities remain unsettled until a terminal response. Tests also cover saved-plan/profile/scope mismatches, changes during inference, native failure without PG ranking, and joined hybrid read arms. The composed integration uses the public native indexer process, actual scoped SQLite vectors/BM25, main scoped capability, a separate qualified public SQLite grep reader, and PG catalog mocks only. It uses controlled vectors and does not perform model inference, launch the application, or establish cross-platform/full-regression acceptance.

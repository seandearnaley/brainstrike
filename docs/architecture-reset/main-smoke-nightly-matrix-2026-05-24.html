Architecture reset follow-up - 2026-05-24

Main pushes become smoke gates. Full proof moves to nightly/manual.

The previous post-merge behavior spent a full release matrix on every merge to main. That was conservative, but too expensive for a pre-release, single-developer project. The new policy keeps merge confidence while moving expensive proof to a scheduled release lane.

Main push gate
Smoke

Static checks, web smoke, and desktop smoke.

Release proof
Nightly

Coverage, browser, full web E2E, desktop regression, and embedding regression.

PR proof
Selected

Still controlled by ci:doctor, exact labels, and the proof manifest.

New Routing

EventWhat RunsWhat Does Not RunGate
pull_request Static checks plus lanes selected by proof labels. Unselected E2E, coverage, desktop, and embedding lanes. Required PR Gate
push to main checks, prepare-web, web-e2e-smoke-pr, prepare-desktop, desktop-e2e-smoke-pr. Coverage, browser tests, full web matrix, stateful/destructive web lanes, desktop regression shards, embedding regression groups. Required Main Gate
schedule The full release matrix. Main-push smoke-only routing. Required Release Gate
workflow_dispatch + release_proof=full-release The full release matrix, intentionally requested. Main-push smoke-only routing. Required Release Gate
workflow_dispatch + release_proof=skip A cheap policy summary only. Static checks, builds, coverage, browser, web E2E, desktop E2E, embedding E2E. None; this is explicitly not release proof.
workflow_dispatch + release_proof=desktop-backgrounding Manual desktop backgrounding diagnostic only. The full release matrix. Diagnostic job result.

Why This Saves Budget

Before

Every merge to main paid for full coverage, browser tests, full web E2E, desktop regression, embedding regression, and report merge.

high runner count high wall time expensive for docs/tooling merges
After

Every merge proves the app still builds and both web and desktop can start through smoke lanes. Full confidence moves to nightly/manual release proof.

bounded main cost release confidence preserved no silent fallback

Contract Coverage

ContractFailure It Prevents

Smoke jobs must include pushEnsures main still has a real health gate.

Release gate requires full matrix jobsKeeps nightly/manual proof meaningful.

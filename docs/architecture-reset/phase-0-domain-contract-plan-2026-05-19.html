Phase 0 stacked PR artifact - May 19, 2026

Domain contract before movement.

This PR creates the deterministic starting point for the pre-release architecture reset. It does not move feature code. It defines the stack, classifies every workspace package into one domain, and adds a validator that future PRs must keep green.

Goal

Make parallel agent work safe by giving every future PR an explicit owner, branch phase, package domain, and planning artifact. The contract prevents accidental unowned packages and makes the reset auditable from `main`.

Non-negotiables

No silent fallback paths. Local embeddings and built-in local LLM remain renderer-only. Local-first PGlite remains the data foundation. Movement happens only after boundaries and release gates are explicit.

Domain owners

Applications

Desktop, web, and docs remain thin composition shells.

Workspace

App shell, explorer, tree worker, DB explorer, and vector UI become one owned domain.

Assistant

Agent runtime, provider selection, local runtime, context, and tools get one owner.

Indexing

File import, chunking, embeddings, pipeline, token cache, and worker runtime align.

Data Platform

DB, queue, storage, and preferences own local-first state contracts.

Foundation and Tooling

Shared UI, types, utilities, config, server config, and build utilities stay foundational.

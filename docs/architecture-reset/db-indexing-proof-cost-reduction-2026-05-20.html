Architecture Ownership

Pipeline now owns backfill decisions

@brainstrike/pipeline now exports background-indexing orchestration helpers for request-id ownership, recoverable backfill selection, superseded backfill cancellation, and coverage-based backfill need.

App-shell is thinner

WorkspaceCollectionSyncService delegates the pure decisions to the pipeline package and remains responsible for UI status, dependency calls, and cancellation wiring.

Sync-service spec reduced

Shared fixtures moved into a local helper. The main sync-service spec dropped from 1,734 to 1,660 lines, and pipeline-specific behavior has a focused pipeline-owned spec.

No broad mocks introduced

DB lanes still execute the real package tests. The split changes command selection and ownership, not behavior coverage through mocked-out database paths.

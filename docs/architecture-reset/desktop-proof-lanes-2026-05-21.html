Architecture Reset / Desktop Proof Economics

Desktop proof is now risk-owned instead of broad by default.

This report records the desktop lane split implemented on codex/desktop-proof-lanes. The purpose is not to weaken desktop confidence: it is to stop small IPC/reset/storage/host changes from paying for unrelated desktop regression shards while preserving full regression for broad main/preload risk.

Pipeline Ownership Decision

Decision

Keep @brainstrike/pipeline and treat it as the indexing orchestration owner for durable embedding queue payload contracts. It is not dormant anymore.

Current Boundary

Pipeline owns queue payload translation and orchestration primitives. It must not own Electron main execution, renderer worker runtime, provider execution, or React UI.

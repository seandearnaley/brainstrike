Selection Rules

File ExplorerTree and persistence changes select ci:web-file-explorer-persistence plus coverage, not import, assistant, settings, destructive, or full web E2E.
Import/IndexingDatabase import and web indexing changes select ci:web-import-indexing and indexing proof commands.
AssistantAssistant contract and UI changes select ci:web-assistant-state plus assistant/app-shell tests.
SettingsSettings persistence changes select ci:web-settings-state only plus coverage.
DB MigrationsMigration changes select data-platform unit/integration proof plus ci:web-db-startup and ci:web-destructive-reset, without expanding to full web regression.
Broad AppApp bootstrap, router, layout, CSS, and broad package surfaces select ci:web-e2e.

Workflow Wiring

What Changed
  • prepare-web now runs for all narrow web labels.
  • Each narrow label maps to one explicit PR job in Required PR Gate.
  • merge-reports includes narrow web jobs without requiring full web regression.
  • Workflow contracts fail if a narrow job falls back to test:e2e:lane:full-regression.
What Did Not Change
  • ci:web-e2e still runs the existing sharded functional, stateful, and destructive jobs.
  • ci:full still expands to the explicit full-risk suite.
  • Desktop proof lanes and renderer-only architecture guards are untouched.
  • Proof manifest policy remains unchanged.

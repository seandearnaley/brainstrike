Phase 1 stacked PR artifact

Guardrails before movement.

Goal

Make architecture checks deterministic before code movement starts. This PR adds a source-code boundary validator over the phase 0 domain contract, creates an explicit package-pair exception baseline for existing cross-domain edges, and turns that baseline into a ratchet: new cross-domain imports fail unless they are intentionally added to architecture/domain-map.json with a reason and retire phase.

Acceptance checks

  • pnpm arch:domain-contract validates package classification, stack order, and exception metadata.
  • pnpm arch:domain-boundaries parses TS/JS imports and rejects unapproved cross-domain imports.
  • The first baseline records 13 package-pair exceptions and reports when all 13 are still in use.
  • Each exception has a retire phase so later PRs can remove them instead of normalizing the debt.
  • The domain contract from phase 0 stays green.

Baseline edges

The current repository checks 1,947 internal imports across 2,758 files. The allowed exceptions are concentrated around assistant contracts, embedding/indexing settings, text-splitter ownership, theme persistence, and worker payload types. Those are not hidden warnings: they are named architecture work items for phases 3 and 4.

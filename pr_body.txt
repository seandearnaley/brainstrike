💡 What: Replaced native `title` attributes on `PromptCard` icon buttons and category badges with Radix `Tooltip` components to prevent double tooltips and improve visual consistency. Added `aria-label` attributes to the `Progress` indicators in `global-download-indicator` and `model-registry-settings-section`.
🎯 Why: Native `title` attributes on icon-only buttons create unstyled hover tooltips that clash with custom app themes, and generic `div` elements lacking roles break screen reader accessibility. `Progress` bars lacking labels provide no context to screen readers about what value is changing.
📸 Before/After: Before, tooltips were unstyled and `Progress` components were unlabeled. Now, tooltips are consistent, and progress values have contextual labels.
♿ Accessibility:
- Added `aria-label` attributes to Radix `Progress` components to give context to screen readers.
- Replaced native `title` with accessible `Tooltip` wrappers on `PromptCard`.
- Added `role="img"` to focusable category `div` elements to ensure the applied `aria-label` is semantically valid.

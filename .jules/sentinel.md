## 2024-05-24 - Unauthorized Window Creation in Background Renderers
**Vulnerability:** Background renderer host processes (like `chunking-host`, `embedding-host`) could potentially open new windows navigating to arbitrary URLs.
**Learning:** While the primary UI windows often explicitly block window opening (e.g., in `create-window.ts`), background headless instances dynamically spawned via `RendererHostLifecycle` lacked a strict `setWindowOpenHandler` denial policy.
**Prevention:** Always explicitly define a `window.webContents.setWindowOpenHandler(() => ({ action: 'deny' }))` for any hidden/background `BrowserWindow` instances to ensure they cannot spawn visible or malicious new windows.

## 2026-04-26 - Add ARIA labels to Progress indicators and accessible disclosures
**Learning:** Disclosure widgets (like expandable error lists) require explicit pairing of `aria-expanded` on the toggle button and `aria-controls` pointing to the ID of the expandable container. Also, progress indicators like `<Progress />` visually convey status but need explicit `aria-label` attributes to ensure their context is accessible to screen readers, especially when they show different metrics (like "Files import progress" vs "Chunks import progress").
**Action:** When using `<Progress />` or creating disclosure widgets, always verify that `aria-label`, `aria-controls`, and `aria-expanded` are correctly set to maintain high accessibility standards.

## Problem 1: Pre-Commit Type-Check Runs on Entire Monorepo

### Issue

```yaml
# lefthook.yml (BEFORE)
type-check:
  run: pnpm turbo run type-check  # ❌ Always runs, checks all 31 packages
```

**Problems**:
- Runs even when no TypeScript files are staged
- Finds pre-existing errors in files you didn't touch
- Blocks commits for unrelated errors
- Slow (checks entire monorepo)

### Fix

```yaml
# lefthook.yml (AFTER)
type-check:
  glob: "*.{ts,tsx,mts,cts}"                      # ✅ Only if .ts staged
  run: pnpm turbo run type-check --filter="[HEAD]"  # ✅ Only changed packages
```

**Benefits**:
- ✅ Skips when no TypeScript files staged
- ✅ Only checks affected packages
- ✅ Fast with Turborepo caching
- ✅ Doesn't block on pre-existing errors

**Documentation**: See `.claude/hooks/LEFTHOOK-CANONICAL-PATTERN.md`

**`packages/ui` has type errors in test files**:

```
src/__tests__/tool-fallback.test.tsx: Property 'toHaveAttribute' does not exist
src/__tests__/unsupported-feature.test.tsx: Property 'toBeInTheDocument' does not exist
src/__tests__/use-panel-layout-provider.test.tsx: Property 'toBeInTheDocument' does not exist
```

**Root cause**: `tsconfig.test.json` doesn't include `@testing-library/jest-dom` types

**Fix options**:

1. Add to `packages/ui/tsconfig.test.json`:
   ```json
   {
     "compilerOptions": {
       "types": ["node", "@testing-library/jest-dom"]
     }
   }
   ```

2. Import in test setup:
   ```typescript
   import '@testing-library/jest-dom';
   ```

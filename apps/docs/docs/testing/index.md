Testing in Brainstrike is layered:

- Unit and integration coverage with Vitest
- Browser and renderer correctness checks
- Electron/web end-to-end coverage with Playwright
- CI parity and flake reduction practices

Read [Testing Standards](/testing/testing-standards) first.

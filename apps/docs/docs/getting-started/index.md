This section is the canonical onboarding path for contributors and agents.

Use this flow:

1. Install toolchain (`node@22`, `pnpm`, `git`, optional Docker).
2. Install dependencies and verify workspace health.
3. Run docs and application dev targets.
4. Run quality gates (lint, type-check, unit/integration, e2e when applicable).
5. Submit changes with a clean check run.

Start with [Onboarding](/getting-started/onboarding).

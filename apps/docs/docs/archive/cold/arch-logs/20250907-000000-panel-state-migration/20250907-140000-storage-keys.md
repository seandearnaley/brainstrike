# Storage Keys and Migrations (Panel State Migration)

This appendix documents the persisted keys introduced or touched during the panel state migration and adjacent feature-state work.

- `panel-layout-store.v1`
  - Source: `packages/app-shell/src/stores/panel-layout-store.ts`
  - Data: ` { sizes: [left,right,console], showLeftPanel, showRightPanel, showConsole }`

- `right-panel.v1`
  - Source: `packages/app-shell/src/stores/right-panel-store.ts`
  - Data: ` { activeTab }`

- `search-panel.v1`
  - Source: `packages/app-shell/src/stores/search-panel-store.ts`
  - Data: ` { query, regex, caseSensitive, wholeWord, includeGlobs, excludeGlobs }`

- `db-panel.v1`
  - Source: `packages/app-shell/src/stores/db-panel-store.ts`
  - Data: ` { activeSubtab, page, pageSize, sortBy, sortDir, filterText }`

- `import-settings.v1`
  - Source: `packages/app-shell/src/stores/import-settings-store.ts`
  - Data: chunking + embeddings settings (primitives only)

- `vector-status-ui-store.v1`
  - Source: `packages/app-shell/src/stores/vector-status-ui-store.ts`
  - Data: ` { activeEmbeddingSetId }`

- `tab-manager.v1` (migrates legacy key)
  - Source: `packages/file-explorer-ui/src/stores/tab-manager-store.ts`
  - Data: ` { tabs[ {id,path,compositeKey}], activeTabId }`
  - Migration: One-time automatic migration from `fileEditorTabs.v1` → `tab-manager.v1` on first access.

- `editor-view-state.v1`
  - Source: `packages/file-explorer-ui/src/stores/editor-view-state-store.ts`
  - Data: ` { scrollTops[key], selections[key] }`

- `editor-cursor.v1`
  - Source: `packages/file-explorer-ui/src/stores/editor-cursor-store.ts`
  - Data: ` { selections[key] }`

- `file-explorer` persistence keys
  - Source: `packages/file-explorer/src/persistence/*.ts`
  - Now includes `quickFilter` in serialized state

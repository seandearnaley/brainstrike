## 🔧 Technical Details

### Store Shape
Location: `packages/app-shell/src/stores/panel-layout-store.ts`

```ts
type PanelTab = 'explorer' | 'settings';

interface PanelLayoutStoreState {
  sizes: [number, number, number];
  showLeftPanel: boolean;
  showRightPanel: boolean;
  showConsole: boolean;
  activeTab: PanelTab;

  setSizes(sizes: number[]): void;               // Validates/clamps 0..100 and normalizes totals
  toggleLeft(): void;                            // Toggle visibility flags
  toggleRight(): void;
  toggleConsole(): void;
  setActiveTab(tab: PanelTab): void;             // Switch root tab
  setState(next: Partial<PanelLayoutStoreState>): void; // Merge setter for batch updates
}
```

### Persistence

- Uses `@brainstrike/storage` adapters with auto platform detection; falls back to in‑memory in non‑DOM contexts
- Persist key: `panel-layout-store.v1`
- Persisted subset only: `sizes`, `showLeftPanel`, `showRightPanel`, `showConsole`, `activeTab`

### Exports


`usePanelLayoutStore` is an HMR‑safe singleton; `createPanelLayoutStore(adapter)` is available for tests or custom instances.

## 🔌 How To Integrate (Phase 2 Preview)

Wire the store into `PanelLayoutProvider` in controlled mode so the provider becomes a thin view over the canonical store. Example:

```tsx
import { PanelLayoutProvider } from '@brainstrike/ui';
import { usePanelLayoutStore } from '@brainstrike/app-shell';

function RootLayoutContentControlled() {
  const state = usePanelLayoutStore((s) => ({
    sizes: s.sizes,
    showConsole: s.showConsole,
    showLeftPanel: s.showLeftPanel,
    showRightPanel: s.showRightPanel,
  }));

  const setState = usePanelLayoutStore((s) => s.setState);

  return (
    <PanelLayoutProvider controlledState={state} onChange={setState}>
      {/* IdeLayout, etc. */}
    </PanelLayoutProvider>
  );
}
```

This preserves the provider’s adapter contracts for uncontrolled mode while enabling a single source of truth in controlled mode.

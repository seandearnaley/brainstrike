# API Contracts — Embeddings + DB (2025)

Stable shapes exported by `@brainstrike/db` and used across apps. These contracts are covered by unit tests and should be treated as source‑of‑truth for UI/API integrations.

## DTOs

### `ChunkSearchOptions`
```
type ChunkSearchOptions = {
  limit?: number;             // default 20
  threshold?: number;         // cosine similarity threshold in [0,1]
  fileRecordId?: string;      // scope to a file
  chunkType?: 'text'|'code'|'sentence'|'recursive';
  embeddingSetId?: string;    // strongly recommended; required on SQL path
};
```

### `ChunkSearchResult`
```
type ChunkSearchResult = {
  chunk: FileChunk;           // matching chunk, may omit `embedding` in SQL fast path
  similarity: number;         // cosine similarity in [0,1]
  rank: number;               // 1..N (sorted by similarity desc)
};
```

### `FileChunk`
```
type FileChunk = {
  id: string;
  fileRecordId: string;
  chunkIndex: number;
  content: string;
  contentHash: string;
  tokenCount: number;
  chunkType: 'text'|'code'|'sentence'|'recursive';
  chunkSize: number;
  embedding?: number[];       // present in fallback path or when explicitly selected
  embeddingSetId?: string;    // set that produced `embedding`
  embeddingUpdatedAt?: string;
  embeddingHash?: string;     // sha256(contentHash:modelKey)
  createdAt: string;
  updatedAt: string;
};
```

### `EmbeddingSet`
```
type EmbeddingSet = {
  id: string;
  modelKey: string;           // registry key used by worker/service
  modelId: string;            // provider/model identifier
  dimensions: number;         // embedding dimensionality
  distance: 'cosine'|'l2'|'ip';
  createdAt: string;
};
```

### `Job` (public shape)
```
type Job = {
  id: string;
  queue: 'embeddings';
  jobType: 'embed_chunk';
  state: 'queued'|'running'|'succeeded'|'failed'|'canceled'|'expired';
  runAt: string;              // ISO
  attempts: number;
  maxAttempts: number;
  leasedUntil?: string | null;
  workerId?: string | null;
  // payload is internal; not exposed in UI
};
```

## Usage Examples

### Search (vector on) — SQL fast path
```
import { FileChunkRepository } from '@brainstrike/db';

const repo = new FileChunkRepository(db); // pgvector required
const queryEmbedding = /* number[] from embedding service */;
const options = { limit: 20, threshold: 0.6, embeddingSetId };
const results = await repo.searchSimilar(queryEmbedding, options);
// results: Array<ChunkSearchResult>, similarity in [0,1]
```

> Note: pgvector is now mandatory. Instantiation fails if the extension is unavailable.

### Queue HUD (stats)
```
import { JobQueue } from '@brainstrike/db';

const jq = new JobQueue(db);
const [{ queued, running, failed, succeeded }] = await jq.getQueueStats('embeddings');
```

### Backfill (dedupe‑safe)
```
// For each chunk missing selected set, enqueue idempotently
await jq.enqueue({
  queue: 'embeddings',
  jobType: 'embed_chunk',
  payload: { chunkId, embeddingSetId },
  dedupeKey: `${chunkId}:${embeddingSetId}:${contentHash}`,
});
```

## Guarantees & Notes

- Similarity is always cosine in [0,1], regardless of path.
- SQL path requires `embeddingSetId` (or exact dimension enforcement) when pgvector is on.
- Client fallback gracefully skips malformed or mismatched embeddings.
- Worker writes `embedding::vector` when pgvector is available; otherwise stores text; both parse consistently.
- Idempotency via `embedding_hash` prevents redundant writes on repeated jobs.

## Exports

These types and helpers are exported from `@brainstrike/db`:

- Types: `ChunkSearchOptions`, `ChunkSearchResult`, `FileChunk`, `EmbeddingSet`, `Job`.
- Repositories: `FileChunkRepository` (and Electron variant where applicable).
- Queue: `JobQueue` and stats helpers.

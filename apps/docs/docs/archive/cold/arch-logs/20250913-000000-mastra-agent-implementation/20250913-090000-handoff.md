Key Decisions (read-me-first)
- Streaming: Web returns newline-delimited JSON chunks compatible with AI SDK v5 consumption. Desktop aggregates chunks via IPC; the renderer pseudo-streams them; Stop cancels iterator.
- Secrets: Never store plaintext. Only encrypted blobs via Electron `safeStorage` + `electron-store`. Preload exposes a narrow API (`window.secrets`).
- Desktop Chat transport: IPC (Option A) preferred over local HTTP to keep surface minimal. A cancellable iterator enables Stop.
- Code blocks: Render safe fenced blocks (no HTML injection). Copy button writes plain text to clipboard.
- MCP: Config lives at `app.getPath('userData')/mcp/mcp.config.json`. Desktop loader decrypts `...Encrypted` header/env values via `safeStorage` and hot-watches file.
- TS/build isolation: Desktop `ipc-agent` imports `@brainstrike/agent` via eval-based dynamic import to avoid bundler resolution issues in tests/builds.

Security & Guardrails
- Never store plaintext keys; only encrypted blobs. Decrypt in main process; keep renderer dumb.
- Keep preload API narrow and validated; no wildcards. Maintain `contextIsolation` and `nodeIntegration: false`.
- Sanitize/escape user-visible content; keep code blocks non-HTML and copy-safe.

Known Pitfalls
- Desktop E2E launch may fail in headless CI without xvfb; verify locally.
- Avoid tight coupling between Electron main and workspace packages; prefer dynamic import or well-defined type surfaces.
- For exactOptionalPropertyTypes, only set optional fields when defined.

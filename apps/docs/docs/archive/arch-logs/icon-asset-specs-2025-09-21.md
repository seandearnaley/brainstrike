### Brainstrike Icon Asset Specs (2025-09-21)

- Source: `icons/000_source_dark.png` (1024x1024, BW gradient). Light variant generated by inversion.

Desktop (Electron builder defaults)
- macOS: `apps/desktop/build/icon.icns` (dark, squircle), `apps/desktop/build/icon-light.icns` (light, squircle)
- Windows: `apps/desktop/build/icon.ico` (dark), `apps/desktop/build/icon-light.ico` (light)
- Linux PNGs: dark `apps/desktop/build/icons/{16,32,48,64,128,256,512,1024}.png`; light in `apps/desktop/build/icons-light/...`

Web/PWA
- Icons (dark): `packages/ui/icons/icon-{16,32,48,192,512}.png`, `apple-touch-icon.png`
- Icons (light): parallel `-light` files
- Maskable: `packages/ui/icons/icon-{192,512}-maskable.png` (+ `-light`)
- Public copies for PWA manifest: `apps/web/public/icons/icon-192x192.png`, `icon-512x512.png`, `icon-192x192-maskable.png`, `icon-512x512-maskable.png`
- Favicons: `apps/web/public/favicon.ico` (dark), `favicon-light.ico` (light)
- Manifest: `apps/web/public/manifest.webmanifest`
- Head links added in `apps/web/src/app/layout.tsx` for manifest and theme-aware favicons

Notes
- macOS: Applied rounded-rect mask for dock shape. Consider refining to Apple’s current superellipse if Apple updates precision.
- Windows: Multi-size ICO includes 256–16px.
- Maskable safe area ~80% per PWA guidance.

- Add tray icons if a Tray is introduced later.
